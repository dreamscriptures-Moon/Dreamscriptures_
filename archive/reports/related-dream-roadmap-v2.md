## Editorial/Data Issues

- **courtroom:** competes with the existing canonical slug `court-room`; this is normalization, not a new topic.
- **cows:** plural label; the proposed canonical concept is singular `cow`.
- **angel / seeing-an-angel:** competing labels are already conceptually covered by `angels`.
- **demon / seeing-a-demon:** competing labels require mapping review against existing presence-related coverage; no new page is recommended here.
- **shadow-person / shadow-figure:** consolidated into one proposed `shadow-figure` page.
- **new-clothes / changing-clothes:** consolidated into `changing-clothes`; new clothes is a scenario.
- **door variants:** locked, black, red, hidden, and walking-through labels should remain scenarios or map to existing door coverage.
- **wedding variants:** wedding, getting married, wedding dress, and missed-wedding labels should not become four competing URLs.
- **mirror variants:** multiple reflection labels overlap the current mirror cluster and need alias/editorial mapping, not another generic page.
- **river variants:** `crossing-a-river` is treated as a scenario of the proposed broad River page.

## Topic-cluster decisions

- Elevator combines the generic elevator label with being stuck in an elevator.
- River absorbs crossing a river as a scenario.
- Shadow Figure consolidates shadow-person and shadow-figure.
- Changing Clothes consolidates new-clothes and changing-clothes.
- Existing door, marriage, mirror, angel, and demon clusters are not expanded into competing pages.
