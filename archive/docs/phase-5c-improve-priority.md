## Reusable editorial patterns

- Form the anchor around a relationship or process, not a theme word.
- Replace inherited fragments and list-like definitions before adding length.
- Use the smallest meaningful scenario set, each with a “why this changes the reading” sentence.
- Derive questions from the anchor; do not add a universal question bank.
- Explain neighbors in terms of the reader’s problem, not only shared nouns.
- Attach trust boundaries to the natural fear of the page (omen, prophecy, diagnosis, betrayal, coercion).
- Keep the ending hierarchy: interpretation → reflection → one primary next action.
